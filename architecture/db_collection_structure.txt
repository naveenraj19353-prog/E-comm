Collection Relationships
Parent Collection	Child Collection	Relationship
Users	Addresses	One User → Many Addresses
Users	Wishlist	One User → One Wishlist
Users	Cart	One User → One Cart
Users	Orders	One User → Many Orders
Users	Reviews	One User → Many Reviews
Categories	Products	One Category → Many Products
Products	Reviews	One Product → Many Reviews
Orders	Products	One Order → Many Products (stored in items)
